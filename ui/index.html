🔑 Get Authentication (Đăng nhập CMS)

Gọi API đăng nhập CMS để tự động lấy csrf_token và cookie session, sau đó tự động lưu vào Biến Toàn Cục.

🌐 Quản Lý Biến Toàn Cục (Global Variables)

Các biến được định nghĩa ở đây có thể dùng ở bất kỳ đâu trong URL, Header, Param, Body theo cú pháp: {{tên_biến}}.

📥 Dán Lệnh cURL (Import to UI)

Dán câu lệnh curl từ Postman, DevTools hoặc tài liệu API vào đây. Hệ thống sẽ tự động tách Method, URL, Headers và trích xuất Body thành mảng payload có STT.
